# 검증 스크립트

## 준비

Playwright 가 필요하다. 저장소 의존성에 넣지 않은 이유는 브라우저까지 받으면 수백 MB 라,
검증을 돌릴 때만 설치하는 편이 낫기 때문이다.

```sh
npm i -D playwright && npx playwright install chromium
```

## AI 통합 검증

```sh
node scripts/verify/ai-suite.mjs
# 로컬 preview 대상
SUITE_BASE=http://localhost:5199 node scripts/verify/ai-suite.mjs
```

운영 배포본에 대해 AI 기능 26개 항목을 확인하고, 실패가 있으면 종료 코드 1 로 끝난다.

**AI 를 실제로 4번 호출한다(실비 발생).** 눈으로 훑는 것과 달리 "된다고 믿었는데 안 되던"
경우를 잡기 위해서다 — 실제로 이 스크립트로 결과 카드 목록 중복과 단계 누락을 찾았다.

확인 범위:
- 예시 탭 3종 · 전체화면 전환
- 역할 목록 / 읽기 전용 배지 / 만들기 다이얼로그의 도구별 안내 전환
- 실행 단계 표시 · 결과 카드 가독성(목록 중복 없음, 전체폭 버튼 없음)
- 역할 도구 제한(점검 도우미로 삭제 요청 → 삭제 단계 없음)
- 대화 저장(localStorage) · 사용량 증가
- JS 오류 0 · 4xx/5xx 0

전제: 둘러보기(게스트) 로그인이 동작하고 체험 워크스페이스에 할 일이 있어야 한다.
